# TAU Moodle Calendar Auto-Sync Extension

Automatically reads your TAU Moodle calendar link and assignment/quiz submission status whenever you visit `moodle.tau.ac.il`, updating your Apple & Google calendars without storing your TAU password.

## Install Locally (Chrome / Edge / Brave / Arc)
1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select this `extension/` directory.
4. Open the extension popup and paste your **App Server URL** and **Workspace Token** from the **Moodle Connector** tab of the web app.
5. Visit [moodle.tau.ac.il](https://moodle.tau.ac.il/) — your problem set completion status syncs automatically!
